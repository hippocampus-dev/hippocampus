## Final Summary

1つの指示に対する作業を終えて次の指示待ちに入る際のレスポンス(最終まとめ)は、以下のテンプレートに厳密に従い、この後の表が省略を認める箇所を除いて、プレースホルダの置換以外の変更を加えてはなりません。

```
---

## 最終まとめ

{{前置き}}

{{逐語反復}}

### 据え置きとした指摘

{{据え置き}}

### 直前の指示とネクストアクション

{{ネクストアクション}}
```

出力するかどうかは以下で決まります。

| 状況 | 最終まとめ |
|------|-----------|
| 1つの指示に対する作業を終えて次の指示待ちに入る | 出力する |
| ネクストアクションが指示待ちで、`### Feedback` がユーザに聞く対象として定めるものがある | 出力してから、同じレスポンスで `### Feedback` が定める形の提示を行う |
| レビューが複数回に分けて到着する | すべて出揃ってから1回だけ出力する |
| 作業が終わっておらず次の指示待ちに入らない | 出力せず、何を待っているかを1行で述べるに留める |
| `{{逐語反復}}` に入れる本文の内容が、そのターンで既に出力した本文と同じになる | `{{前置き}}` と `{{逐語反復}}` の2行だけを省き、残りはテンプレートのまま出力する |
| ユーザ以外から届くプロンプトに対する応答で、直前に出力した最終まとめに読み手の判断を変える訂正も追加も生じない | 出力し直さず、点検して差分が無かったことを1行で述べるに留める |

複数の行に当てはまる場合は、下にある行が上にある行に優先します。

`{{前置き}}` は本文を読み手が既に読んでいるかを示す1行で、以下の文面をそのまま入れます。

| 本文 | `{{前置き}}` |
|------|-------------|
| 訂正・追加を反映して書き直したもの | 以下は直前の実質的なレスポンスに訂正・追加を反映した本文です。 |
| そのレスポンスで初めて出す文章 | 入れず、`{{前置き}}` の行ごと省く |

`{{逐語反復}}` に入れる実質的なレスポンスは以下のとおりで、そこから省略・抽象化してはなりません。

| 場合 | 実質的なレスポンス |
|------|-------------------|
| 通常 | その指示に対して最後に出力したレスポンス(停止時チェックの差し戻し、リマインダ、サブエージェントの結果など、ユーザ以外から届くプロンプトへの応答や進捗連絡は含まない) |
| そうしたプロンプトを契機に読み手の判断を変える内容の訂正・追加や `### Feedback` がユーザに聞く対象として定める指摘の提示が生じた | それを反映してユーザ向けに書き直した本文 |
| 実質的なレスポンスを複数出しており、最後のものに含まれない内容が先行分にある | 先行分の内容も反映してユーザ向けに書き直した本文 |
| その指示への回答をこのレスポンスで初めて出す | その回答本文 |

書き直した本文は単体で読んで意味が通る必要があり、差し戻しの項目番号のようなユーザに見えない文脈を指してはなりません。
`{{据え置き}}` はその時点でタスクリストに未完了で残っている据え置き項目を、その指示で登録したものか以前からのものかを問わず1行1件で入れる箇所で、記憶から書き起こさず、登録した件名をそのまま引きます。
該当がなければ「なし」の1行だけを入れます。
`{{ネクストアクション}}` は直前の指示と、完了したのか、指示待ちなのか、待っているなら何を待っているのかを入れる箇所で、既にある記述を指す場合はその記述そのものを引きます。
`{{据え置き}}` の各行に収まらない判断材料は、`{{逐語反復}}` に反復される元のレスポンスの末尾に、`{{据え置き}}` に入れる件名を先頭に置いてまとめておきます。
