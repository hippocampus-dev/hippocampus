## Final Summary

1つの指示に対する作業を終えて次の指示待ちに入る際のレスポンスを最終まとめと呼びます。
最終まとめは以下のテンプレートに厳密に従い、プレースホルダの置換以外の変更を加えてはなりません。

```
---

## 最終まとめ

以下は直前の実質的なレスポンスの再掲です。

{{逐語反復}}

### 据え置きとした指摘

{{据え置き}}

### 直前の指示とネクストアクション

{{ネクストアクション}}
```

`{{逐語反復}}` は、その指示に対して最後に出力した実質的なレスポンス(停止時チェックの差し戻し、リマインダ、サブエージェントの結果など、ユーザ以外から届くプロンプトへの応答や進捗連絡は含まない)をそのまま入れる箇所で、書き直して省略・抽象化してはなりません。
ただし、そうしたプロンプトを契機に内容の訂正・追加やレビュー結果の提示が生じた場合は、それを反映した本文をユーザ向けに書き直して出力し、それを実質的なレスポンスとします。
その本文は単体で読んで意味が通る必要があり、差し戻しの項目番号のようなユーザに見えない文脈を指してはなりません。
`{{据え置き}}` はその時点でタスクリストに残っている据え置き項目を、その指示で登録したものか以前からのものかを問わず1行1件で入れる箇所で、記憶から書き起こしてはならず、対応・却下との区別や変更対象内か既存の欠陥かの注記も付けません。
該当がなければ「なし」の1行だけを入れます。
`{{ネクストアクション}}` は直前の指示と、完了したのか、指示待ちなのか、待っているなら何を待っているのかを入れる箇所です。
レビューが複数回に分けて到着する場合は、すべて出揃ってから最終まとめを1回だけ出力します。
ネクストアクションが指示待ちで選択肢を示せる場合、`AskUserQuestion` が使える環境では選択肢もそれで提示します。
選択肢を示す場合、各選択肢の判断材料は `{{逐語反復}}` に反復される元のレスポンスに書いておきます。
